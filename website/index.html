It watches, so you do not have to

A key goes into your keychain

Paste a key once. Meterix checks it against the provider before replacing anything, then hands it to the operating system's keychain. It never reaches the database.

Each provider is read on a timer

Thirty minutes by default, or an interval you set for one provider alone. A provider that rate-limits can be given hours without the others waiting behind it.

The tray shows the worst state

Teal when everything is fine, amber when a balance is under your threshold, copper when a key has stopped working.

Four providers, chosen because they answer

Meterix can only show what a provider is willing to report. These four say how much is left, and more can be added without rebuilding it when a gateway speaks a shape Meterix already understands.

OpenRouter

Account balance, plus spend over the last 90 days.

In dollars

CheaperInference

Account balance, and the balance it auto-recharges at.

In dollars

DeepSeek

Prepaid balance, including any credit that was granted rather than bought.

In dollars

ElevenLabs

A monthly character allowance, so it is counted in characters and kept out of the money total.

Not money

Audited and left out. OpenAI and Anthropic report spending rather than a balance, and only through an admin key that an individual account cannot always have. Groq reports neither. AWS Bedrock has no balance endpoint at all, and signs requests instead of accepting a key.

What it costs to leave running

Measured on a release build with two providers connected, ninety seconds after launch. It is a tray app, so these are the numbers that matter.

Its own process
29 MB

The rest of the memory is the Edge runtime the window is drawn in.

CPU while idle
0.4%

Of one core. At a 30 minute poll that is about 7 CPU-seconds a day.

Database
~100 B

Per reading, so a few megabytes a year at the default rate.

Release binary
15.8 MB

Nothing needs OpenSSL or a system crypto library.

What it does not do

Worth reading before you rely on it. A balance watcher that overstates itself is worse than none.

By design

  • It reads balances. It is not a cost calculator and not a proxy, so nothing you send to a provider goes through it.
  • There is no account, no cloud and no sync. The database is one file on your machine.
  • Four providers to start with, and more by configuration. Which providers are watched is data, and a gateway that speaks a shape Meterix already understands can be added from the command line. A provider whose API speaks a new shape is still a code change.
  • Desktop only. There is no mobile app and no web version.

Not finished yet

  • There is no installer. You build it from source, which the section below walks through.
  • Dark only. There is no light theme.
  • Windows is the only platform this has been run on. macOS and Linux are in the code and untested.
  • A DeepSeek account funded in yuan is refused rather than shown, because everything else here is compared against a dollar threshold.

Get it

Clone the repository and build it. Rust 1.85 or newer, Node 22 or newer, and WebView2, which Windows 11 already has. Nothing needs OpenSSL. 

# build and run
git clone <repository> meterix
cd meterix/app
npm install
npm run tauri dev

# release build
npm run tauri build

The repository link will go here once it is published.

No installer yet

There is no download, and this page will not pretend otherwise. The bundler needs to fetch NSIS on first use and that download has not completed in the environment this was built in, so no installer has ever been produced. When there is one, it will appear here.

Use npm run tauri build rather than a plain cargo build. A bare release build produces a binary that loads the development server, so it opens an error page with no JavaScript running at all. It looks like it worked.
