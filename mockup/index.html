Decisions
  • · The two badges are gone. One button, showing the provider the key will be saved to.
  • · The name, not a monogram. Identity should not have to be learned.
  • · Each row says whether a key is already stored, so replacing one is a visible act.
  • · Choosing a provider only picks the slot. Nothing is written until you save.
  • · The line under the row shows the stored key's last four characters.
Found while doing this

The cards and the table render provider names with CSS capitalize, so "cheaperinference" shows as Cheaperinference and the internal capital is lost. A display name per provider fixes it. The correct casing is used above.
