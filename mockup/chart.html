Balance over time — chart options

Four directions for the same data, with real hover on all of them. Move the cursor across a plot to see the crosshair and tooltip. Nothing here is applied to the app yet.

A Line, scaled to the data Recommended

No fill at all, so the gridlines stay visible and nothing hides the shape. The y-axis is fitted to the readings with a little padding rather than starting at zero. That is the real fix: a balance between $6 and $12 squeezed onto a 0–$20 axis is a nearly flat line, while a $6–$12 axis shows the movement that actually matters. The cost is that a small wobble looks big, so the axis labels stay visible to keep it honest. Each line ends with its current value, so you don't have to match colours against a legend.

B Line with a fading fill Keeps the weight

Same scaling as A, but the area under each line fades to nothing instead of staying solid. It keeps some of the mass the current chart has without becoming a wall of colour, and overlapping providers still read as separate. Slightly busier than A; with two providers the fills do overlap.

C Step line Most honest

Readings are discrete samples, so a step holds each value until the next reading replaces it, instead of drawing a slope through time we never measured. A straight line between two points quietly claims the balance slid evenly from one to the other. This is what the data actually says. It reads slightly less elegant when a provider moves every poll.

D One row per provider Own scale each

Same data as the others would look almost identical to A, because your two providers sit at similar magnitudes. So this sample is deliberately stretched: one provider around $6, the other around $180. On a shared axis the cheap one would be a flat line pinned to the bottom; here it is fully readable. The trade-off is direct comparison — you can no longer see at a glance which provider is worth more, because the axes differ. It also costs vertical space per provider.

Tooltip. In every option the hover shows a crosshair, dots on each line at that reading, and a panel with the date and each provider's value. The panel flips side near the right edge so it never runs off the window.
